# Моя цель — Apple Edition

Личное приложение для контроля заработка в такси. Интерфейс переработан в духе iOS: системная типографика, светлая палитра, мягкие поверхности и плавающая нижняя навигация.

## Возможности

- План и прогресс по дням
- Календарь, недели и статистика
- Отдельный учёт заправок
- Локальное сохранение записей в браузере
- Импорт и экспорт резервной копии
- Установка как PWA и кэширование оболочки для повторного открытия без сети

## Публикация

Это статический Web App. Для GitHub Pages выберите **Settings → Pages → Deploy from a branch**, ветка `main`, папка `/ (root)`. После сохранения приложение будет доступно по адресу GitHub Pages вашего репозитория.

## Данные

Записи сохраняются в `localStorage` браузера на устройстве. Для переноса между браузерами или устройствами используйте раздел «Настройки» → «Данные и резервная копия».
